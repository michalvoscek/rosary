# Page switching animation

When switching between major pages like home page, prayer page and calendar pages there should be animation.
Animation duration should be 150ms.
Animation should be horizontal and in both directions:

1. from right <- to left
2. from left -> to right

Option 1 should be used when going froward (browser navigation) or when changing page by clicking any link (except when target is home page).
Option 2 should be used when going back (browser navigation) or when going to home page(special page).
On desktop animation should extend to beyond original component borders to partially use bigger left and right padding/margin.
