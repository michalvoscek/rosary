# Settings

Separate page that should be accessed by clicking cogwheel icon in app header.
List of settings available is following:

1. language change - dropdown with available languages
2. theme picker - use dark and light colors, picker should display color used in picker
3. install button
  - uses `beforeinstallprompt` to check for installable env if one found
  - display button to install as PWA
  - on ios it should diplay instructions to install thru "Add to Home Screen"
